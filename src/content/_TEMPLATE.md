# Page Template: File-Type Subpages

Every file-type subpage (e.g., /text-alternatives/word, /color/powerpoint) should follow
this section order. Not every section is required for every page, but the ORDER must be
consistent. Omit sections that genuinely don't apply; do not reorder.

1. ## The Ally Error (always required)
   - Ally Error Message callout component
   - Severity + WCAG criterion

2. ## Why This Matters (always required)
   - 2-3 paragraphs, second-person voice, concrete student impact examples
   - Audio before/after (if available for this category)

3. ## How to Fix It (always required)
   - Numbered steps with screenshots
   - Sub-sections for different fix approaches (e.g., "Fix in source" vs "Fix in Acrobat")

4. ## [Category-Specific Guidance] (varies)
   - e.g., "Writing Good Alt Text" for text-alternatives
   - e.g., "Color as Sole Means (1.4.1)" for color
   - Includes Examples table when applicable

5. ## What Ally Catches (always required)
   - Green checkmark callout

6. ## What Ally Misses (always required)
   - Warning callout with specific gaps

7. ## Check It With Other Tools (include when tools exist)
   - Microsoft Accessibility Checker
   - Acrobat (for PDF pages)
   - axe DevTools / WAVE (for Canvas pages)

8. ## The Student Side (include for Word and Canvas pages minimum)
   - Brief paragraph on students as content creators
   - Suggested assignment instruction text

9. ## Quick Reference (always required)
   - Two-column table: label | value

10. ## Resources (always required)
    - External links with descriptions
